# R56フォローアップ：完了報告へのコミットハッシュ明記 指示書（Codex向け）

## 背景

`doc/reports/2026-07-12_r56_agents_md_sync.md`（AGENTS.mdのクロスワークスペース同期追加）の実装内容・検証（SHA-256一致確認、一方向性の実測、既存タスクへの相乗り確認）は妥当と評価している。

しかし、AGENTS.md「完了主張の根拠明記」節が定める「根拠となるコミットハッシュ...を必ず明記すること」を満たしていない。報告書「検証」節は実装コミットの**メッセージ**（`feat(ops): sync AGENTS.md to Claude workspace (R56)`）のみを記載しており、**実際のコミットハッシュ文字列**を明記していない。これはR54完了報告で一度指摘した内容と同じ種類の不備であり、再発している。

念のため確認する：**これはリモートへのpush未実施とは無関係である。** コミットハッシュは`git commit`した時点でローカルに確定するものであり、push有無に左右されない。push自体はAGENTS.md「禁止事項」の通り、人間の明示承認なしに行ってはならない（この方針は変更しない）。今回求めるのは、push可否とは独立に、既にローカルに存在するコミットのハッシュ値を報告書に書き写すことだけである。

## 作業

1. R56の実装変更を含むコミットのハッシュ（`git rev-parse HEAD`または`git log -1 --format=%H`等、push不要でローカル取得可能）を特定する。
2. `doc/reports/2026-07-12_r56_agents_md_sync.md`の「検証」節（または該当箇所）を更新し、実装コミットのハッシュ値（短縮形・完全形のいずれか、可能なら両方）を明記する。
3. `doc/work_orders/active/codex_r56_agents_md_sync.md`がまだ`active/`に残っている場合、本追記のコミットと同一コミットで`doc/work_orders/done/`へ移動する（AGENTS.md「Completion Report Move Rule」に従う）。

## スコープ外

- リモートへのpushは引き続き行わない（本タスクの対象外、かつ禁止事項のまま）。
- ドキュメントのみの変更のため、プロセス再起動・テスト再実行は不要。
