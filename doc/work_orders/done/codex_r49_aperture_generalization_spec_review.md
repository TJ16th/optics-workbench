# 絞り定義の一般化：固定遮蔽（副鏡型）とフォーカス連動可変絞り（マクロレンズ型） 仕様検討メモ

これはP005個別の修正ではなく、**エンジン仕様レベルの設計課題**として記録・検討する。実装はまだ行わない。

## 背景

R40〜R48のP005（カセグレン）調査を通じて、「annulus絞り」という専用の仕組みが、副鏡による中央遮蔽を表現するために場当たり的に追加されたことで、Systemタブ表示の欠落（R47）や絞り構成の重複・整合性の問題（R48）を招いている可能性が高いことが分かってきた。

人間から「カセグレンに限らず、ちゃんと適用できるような絞り定義がいい」「マクロレンズだと、副絞りがフォーカスポジションで可変径・位置であったりもする」という指摘があった。これは、現在の絞りモデル（`aperture_stop`：系に1つの可動主絞り、`mechanical_aperture`：固定副絞り）が、実務で必要になる2つの異なるユースケースを十分にカバーできていないことを示している。

## 整理すべき2つのユースケース

### A. 固定的な遮蔽（副鏡型）

カセグレン式望遠鏡の副鏡による中央遮蔽のように、**遮蔽の原因となる光学要素（副鏡）自体が、遮蔽の形状を決めている**ケース。

**用語の整理（重要）**：通常の絞り・面の有効径判定（仕様17.3節）は「半径の外側を遮蔽する」（外径側の制限）。annulus絞りが表現しているのは「半径の内側を遮蔽する」（内径側の制限、逆ドーナツ状）。この2つは遮蔽の向きが逆であることに注意する。

さらに、内径側の制限（②）には、原因の性質によって2つの下位パターンがある：

- **②-a：遮蔽の原因が実体を持つ後続面自体（副鏡型）**：副鏡M2という光学面が、その物理的な存在（有効径）によって、手前の光路の中心付近を自然に遮っている。この場合、専用のannulus絞り面を別途置かなくても、**M2自身の`semi_diameter_mm`を、その手前の光路に対して内径側の制限として適用する**（つまりM2の有効径判定を、前方の光束に逆向きに伝播させる）ことで、専用面なしに表現できる可能性がある。
- **②-b：遮蔽の原因が実体を持たない機械的制約（鏡筒内壁・遮光環等）**：対応する光学面が存在せず、純粋に「この範囲を通さない」という機械的な制限のみが必要なケース。この場合は、現行のannulus絞り（`shape: annulus`、専用面）の仕組みがそのまま適している。

**検討事項**：
- ②-aと②-bを区別する設計にするか、それとも統一的に扱うか（例えば「面が内径遮蔽を持てる」という汎用的な属性を全ての面種別に持たせ、annulus絞りは②-bの特殊ケースとして残す、等）を検討する。
- 現在の遮光判定（仕様17.3節）は「その面自身の有効径を超える光線を遮光する」という外径側のロジックのみである。②-aを実現するには、ある面の有効径が、それより前段の面の通過可能範囲に影響を与える、という前方への伝播的な扱いが必要になる。この実現方式（例えば「次の面のsemi_diameter_mmを、現在の面のannulus内径として自動的に参照するオプション」等）を検討する。
- annulus絞り専用の仕組み（②-b用）自体は維持しつつ、②-aについては新しい表現方法を追加する、という two-track の対応が妥当か判断する。

### B. フォーカス連動の可変絞り（マクロレンズ型）

マクロレンズ等で見られる、フォーカス群の移動に連動して径・位置が変わる副絞り（vignetting stop、浮動絞り）。

**検討事項**：
- 現在の`mechanical_aperture`は固定絞りとして定義されているが、径・位置が固定である。
- 仕様10章の群定義（`groups`）・ズーム/フォーカス位置（`zoom_positions`、`group_positions`）の仕組みを流用し、`mechanical_aperture`面を群に含めることで、フォーカス位置ごとに径・位置を変えられるようにできないか検討する。
- 絞り自体の径（`semi_diameter_mm`）が、ズーム/フォーカス位置ごとに異なる値を持てるようにする拡張が必要か検討する（現状の`group_positions`はX位置の変更のみを扱っており、径の変更は想定されていない可能性がある）。
