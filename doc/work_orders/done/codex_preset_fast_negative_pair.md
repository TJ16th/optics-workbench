# プリセット追加：明るいF値の正負2枚組（Layout View検証用） 指示書（Codex向け）

## 背景

現在のプリセット一覧（P001, P002, P003, P005, P006）には、以下が欠けている：
- 強い凹レンズを含む系（R1・R2差が大きい発散面）
- 明るいF値で周辺光線の屈折が視覚的にダイナミックな系

これらを兼ね備えた新規プリセットを追加し、あわせて現在進行中のLayout View描画品質改善（有効径境界・エッジ厚表現・材質区別）の検証ケースとしても使う。

**着手前提**：Layout View描画品質改善（`codex_layout_view_rendering_quality.md`）の作業と競合しないよう、当該タスクが完了報告を出してから本タスクに着手する。もし並行実行が既に指示されている場合は、`presets.ts`への追記のみを行い、Layout View描画ロジック自体には触れない。

## 作業

1. 新規プリセット（案：P007、または既存の欠番があればそちらを使う）として、**強い正メニスカス＋強い凹メニスカスの2群構成、F1.4〜F2クラス**のレンズを設計する。
   - 目安：焦点距離50mm、F1.8程度。第1群は強い正パワー（例：R1が小さい正の値）、第2群は強い負パワー（発散）を持ち、全体として正パワーに収束する。
   - 硝材はP003同様、既存のカタログ硝材（N-BK7、N-F2等）から選ぶ。
   - 絞りは2群の間または適切な位置に配置する。
2. 近軸検証を行う（仕様9.1節の数値検証規約に従う）：EFL・BFL・F値が意図通りになることを確認し、破綻しないことを近軸トレースで確認する。実光線トレースでも周辺光線（絞り縁付近）がケラレなく像面に到達することを確認する。
3. `apps/workbench-ui/src/domain/presets.ts`に追加する。名前・説明文（ja/en）はglossaryの翻訳境界規約に従う（識別子は翻訳しない、説明文は翻訳する）。
4. i18nリソースへプリセット名・説明を追加し、`npm run i18n:coverage`をグリーンに保つ。
5. Layout Viewで実際に表示し、以下を確認する：
   - 正メニスカスと凹メニスカスの曲率の違いが視覚的に明確に分かる。
   - 絞り開放時、周辺光線が中心光線と比べて大きく異なる角度で屈折している様子が見える。
   - Layout View描画品質改善タスクの成果物（有効径境界線、材質区別、線の視認性）がこのプリセットでも破綻しないことを確認する。

## 完了条件

- 新規プリセットが選択でき、近軸検証結果が報告されている。
- Layout Viewで凹レンズの発散と、明るいF値による周辺光線の大きな屈折が視覚的に確認できる（スクリーンショット添付）。
- 既存プリセット・テストに影響がないこと（回帰確認）。
- 完了報告前に、AGENTS.mdの規約に従いプロセスを再起動し、`build_info.git_commit`がHEADと一致していることを確認する。
