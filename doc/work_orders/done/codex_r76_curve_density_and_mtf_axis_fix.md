# R76：像面湾曲・周辺光量・歪曲のプロット点密度／MTF軸範囲 修正 指示書（Codex向け）

## 背景

人間からUI操作時の2点の指摘があった。

1. 像面湾曲・周辺光量・歪曲のグラフの点が粗い（見づらい）。
2. MTFチャートの横軸は0から開始し、縦軸は0〜1であってほしい。

1点目について、R70・R72の調査記録では、これら3つの解析はいずれもプリセットの推奨3 field（center/mid/edge）だけをプロットしており（例：P002で周辺光量はcircle3個、Field Curvatureはcircle6個、Distortionはcircle2個）、これが点の粗さの原因である可能性が高い。ただし記録は過去時点のものであり、現状を実データで確認してから対応すること。

像面湾曲・周辺光量・歪曲はいずれもfield角に対する連続的な関数であり、spot diagramやMTFのように特定fieldでの詳細評価が目的の解析とは性質が異なる。滑らかな曲線として見せるには、離散的な代表fieldだけでなく、0からmax fieldまでの範囲を密にサンプリングしたfieldリストが必要である。

## 作業1：像面湾曲・周辺光量・歪曲のプロット点密度向上

1. 現状、これら3つの解析がAPIへ渡しているfieldの数・角度を実データで確認する（R70/R72の記録を鵜呑みにせず、現在のコードで再確認すること）。
2. これら3つの解析専用に、0からmax field角まで（プリセットのfield定義に基づく）を適切な密度（目安：9〜21点程度、既存のray fan等のサンプル数規約を参考にしてよい）でカバーするfieldリストを生成し、APIへ渡すよう修正する。
3. spot diagram、ray fan、MTF等、他の「特定fieldでの詳細評価」を目的とする解析には本変更を適用しない（推奨3 fieldのままでよい）。
4. 点密度を上げたことで、既存の代表3 field（center/mid/edge）の値が変化しないこと（同じ計算方式・同じ値であること）を確認する。
5. 修正後のスクリーンショットで、密度向上が視覚的に確認できることを示す。

## 作業2：MTFチャートの軸範囲固定

1. 現状のMTFチャートの横軸（空間周波数）・縦軸（MTF値）の範囲設定を実データで確認する。
2. 横軸を0から開始するよう固定する。
3. 縦軸を0〜1の範囲に固定する（自動スケーリングによって範囲が変わらないようにする）。
4. white MTF・monochromatic MTF（R73作業3で追加済み）の両モードで、この軸範囲が一貫して適用されることを確認する。
5. 修正前後のスクリーンショットを取得する。

## 完了条件

- 作業1：像面湾曲・周辺光量・歪曲のプロット点数が、修正前後で実データ・スクリーンショットにより比較され、密度が向上していることが示されている。代表3 fieldの値が変化していないことが確認されている。他の解析（spot、ray fan、MTF等）には影響がないことが確認されている。
- 作業2：MTFチャートの横軸が0開始、縦軸が0〜1固定になっていることが、実DOM・スクリーンショットで確認されている。white/monochromatic両モードで一貫していることが確認されている。
- 修正が近軸値・実光線追跡結果の数値自体に影響を与えていないことを確認している（表示密度・軸範囲の調整のみ）。
- 既存テストがグリーン。DOM構造の変更に伴うE2Eテストの更新が必要であれば行っている。
- 完了報告前にプロセスを再起動し、`build_info.git_commit`がHEADと一致することを断定形で記載する（未来形で締めない）。
