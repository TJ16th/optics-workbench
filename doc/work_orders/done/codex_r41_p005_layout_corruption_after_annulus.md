# R40後続：annulus STOP追加によるP005レイアウト座標破壊の緊急調査 指示書（Codex向け）

## 背景

R40でP005に開口絞り面（annulus形状）を追加する修正を行った。人間が実際にブラウザで確認したところ、**新たな重大な破綻**が発生している：

1. M2（副鏡）が画面左下の遠く離れた位置に誤って描画されている（本来はM1・IMGと光軸上、左端付近にあるべき）。
2. STOPとM1がほぼ同じ位置に重なって表示されている。
3. 光線経路が、誤配置されたM2の位置を経由するかのように、画面上下の遠方まで飛んでから折り返す不自然な形になっている。

annulus絞り追加という、本来はレイアウト座標に影響しないはずの変更が、ミラー系の座標計算・レイアウト配置ロジックに予期しない影響を与えた可能性が高い。

## 作業

1. **原因調査（最優先、推測で直さない）**：
   - R40で追加したSTOP面（annulus形状）の`thickness_after_mm`・面順序が、P005の既存面構成（M1、M2）の座標計算にどう影響しているか確認する。
   - 特に、ミラー系の座標計算（propagation_sign反転、6.3節の伝播規約）が、新しく挿入されたSTOP面によって面のインデックス・累積X座標のどこかがずれていないか確認する。
   - STOP面の挿入位置（M1の前か後か、絞り面としてどこに配置したか）が、仕様6.3節のカセグレン検算例の構成（ENTRANCE→M1→M2→IMGの順、絞りは入射側先頭に置く想定）と一致しているか確認する。
   - Layout View側の座標計算（面のX位置、Y方向の描画スケール）が、この新しいSTOP面を正しく扱えているか、それとも面数が変わったことで何らかのインデックス依存の計算が崩れているか確認する。
2. 原因を特定した上で修正する。
3. 修正後、以下を確認する：
   - M1・M2・STOP・IMGが、正しい光軸上の位置関係（近軸検算：M1後650mm相当の位置にM2、M2後1050mm相当の位置にIMG等、仕様6.3節の検証値）で描画される。
   - 光線経路が、STOP→M1→M2→IMGの順で物理的に妥当な折れ線として描画される（不自然な遠方への飛び出しが無い）。
   - annulus中央遮蔽が視覚的に確認できる（R40本来の目的）。
4. この修正により、R40で確認したannulus遮蔽の機能自体に影響が無いか再確認する。
5. なぜこの座標破壊がR40の作業時に検出されなかったのか（テスト・E2Eでカバーされていなかった理由）を報告し、再発防止のためのテスト観点を追加する（例：面構成を変更するタスクでは、必ず全面のレイアウト座標がリポジトリの近軸検証値と一致することを確認するテストを実行する、等）。

## 完了条件

- P005のLayout Viewで、M1・M2・STOP・IMGが正しい光軸上の位置関係で描画される。
- 光線経路が物理的に妥当な折れ線として描画される。
- annulus中央遮蔽が視覚的に確認できる。
- 座標破壊の原因が明確に報告されている。
- 再発防止のためのテストが追加されている。
- 完了報告前にプロセスを再起動し、`build_info.git_commit`がHEADと一致することを確認し、断定形で報告に記載する（未来形で締めない）。
