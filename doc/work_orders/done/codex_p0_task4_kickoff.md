# P0-7 タスク4 着手指示

## 対象

`doc/work_orders/active/codex_p0-7_performance_work_order.md`のタスク4（瞳アフィン写像とwarm startキャッシュ）に着手する。

## 前提

- タスク0〜3は完了済み。タスク3で「full ray aimingのchief ray完全ベクトル化Newtonは未実装で、タスク4に委ねる」と明記された。
- タスク3時点のベンチ：14面1万本offが98ms（必須目標200ms達成、努力目標50ms未達）、教育preview 3.6ms。
- 現状のaimingは、タスク2で軽量化したresidual計算を使いつつも、瞳サンプルごとに個別のNewton反復を行っている（タスク3の残件）。

## 実施内容

指示書のタスク4に定義された内容をそのまま実施する：

- field×波長ごとに、主光線＋絞り縁サンプル（decenter/tilt無しなら4点、ありなら8点）のみを厳密aimingし、絞り面上の実効瞳のアフィン写像（中心＋楕円）を構築する。
- 中間の正規化瞳座標はこのアフィン写像で生成し、解析モードでは絞り面到達誤差が閾値を超える光線のみ追加反復する。previewモードでは追加反復を省略する。
- aiming解キャッシュを実装する。キー：`system_hash + configuration_hash + field + wavelength + stop半径`。配置パラメータ変更時は該当fieldのみ無効化し、前回解をwarm startの初期値に使う。
- 偏芯・チルト系ではmode: fullを強制し、絞り縁サンプルを8点以上に増やす。
- 検証テスト：アフィン近似で生成した光線束の絞り面充填の一様性（到達点の重心ずれ・被覆率）を、全点厳密aimingと比較するテストを追加する。
- ベンチ再実行し、before/afterを報告する。目標（指示書記載）：Spot簡易解析（5field×3λ×512rays）1秒以内、最適化粗評価（evaluate fast_design_score）500ms以内。あわせてタスク3の努力目標（14面1万本50ms以内）への到達状況も報告する。

## 作業規律の確認

- **タスク4完了後、完了報告を出してこのセッションで停止する。タスク5以降には進まない。**
- Golden Test・等価性テスト（タスク3で追加済み）を再実行し、アフィン近似・キャッシュ導入後も数値精度が許容差内に収まることを確認する。アフィン近似は「近似」なので、厳密解との差が生じうる点に注意し、許容差を明示的に決めて報告すること（Golden Testの`atol`と同一水準を求めるか、別途アフィン近似専用の許容差を設けるかは判断して報告する）。
- 偏芯・チルト系での±field自動評価・非対称性が、キャッシュ導入後も正しく機能することを確認する（Phase 3のP003拡張プリセット等で確認できると良い）。

## 完了条件

- 全テスト（既存＋Golden＋等価性＋アフィン充填一様性）グリーン。
- ベンチ目標（Spot簡易解析1秒以内、最適化粗評価500ms以内）の達成状況。
- warm start有無でのaiming反復回数の比較。
- タスク3の努力目標（50ms以内）への到達状況。
