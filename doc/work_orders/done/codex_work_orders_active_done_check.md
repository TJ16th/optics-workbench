# doc/work_orders active/done 整理状況確認 指示書（Codex向け）

## 背景

G9（2026-07-09）で`doc/work_orders/`直下をactive/doneのみに整理したが、その後Q1、Q1-symmetry、R2など複数のタスクが完了している。これらの指示書ファイルが`active/`に残ったままになっていないか確認する。

## 作業

1. `doc/work_orders/active/`の中身を一覧化する。
2. 各ファイルについて、対応する完了報告（`doc/reports/`）が存在するか確認する。
3. 完了報告が存在するものは`done/`へ`git mv`する。
4. 完了報告が存在しない（＝まだ実行されていない、または報告待ち）ものは`active/`に残す。判断に迷うものがあれば一覧化して報告する。
5. `doc/work_orders/done/`の中身も一覧化し、最終的な状態を報告する。
6. 今後この種の取りこぼしが起きないよう、AGENTS.mdの作業規律に「タスク完了報告を`doc/reports/`に追加する際、対応する指示書ファイルを同じコミットで`active/`から`done/`へ移動する」旨を追記する（まだ明記されていなければ）。

## 完了条件

- `active/`に、報告未完了のタスクの指示書のみが残っている。
- `done/`に、完了済みタスクの指示書がすべて集約されている。
- 移動対応表（旧パス→新パス）が報告されている。
- AGENTS.mdへの再発防止の追記が完了している（既にルールがあれば、それが守られていなかった理由を報告する）。
