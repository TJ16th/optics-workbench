# R79：幾何MTFの異常な波形（振動・中域での急回復）調査・修正 指示書（Codex向け）

## 背景

R78で幾何MTFの周波数サンプリングを5点から33点へ高密度化したところ、人間がP002のMTFカーブに次のような物理的に不自然な形状を発見した。

- 0 lp/mmで1.0から単調に減衰するのではなく、いくつもの山谷を繰り返す（振動する）。
- 中間周波数（約50 lp/mm付近）で一度大きく落ち込んだ後、再びほぼ1.0近くまで急回復する箇所がある。

単純な球面単玉（P002）のMTFがこのように激しく振動し、中域で1.0近くまで回復することは、通常の収差・回折特性としては考えにくい。

R74・R75で、周辺光量（Relative Illumination）が同種の問題（UIの共有`ray_sampling`既定値9 raysをそのまま使っていたため精度不足）を抱えていたことが判明し、修正済みである（周辺光量専用に1000 rays/fieldへ既定値を引き上げ）。`doc/engine_spec.md` 22.3節によれば、幾何MTFは「幾何PSFからフーリエ変換して簡易MTFを求める」方式であり、20.2節は幾何PSF自体に4096〜100000 rays/fieldという多数のサンプルを推奨している。**MTFの基礎となる幾何PSFの計算が、周辺光量と同様にUIの共有ray_sampling（既定9 rays等）をそのまま使っている場合、PSFヒストグラムが粗すぎてFFT後のMTFに深刻なノイズ・エイリアシングが生じ、観測された振動・不自然な回復を引き起こしている可能性が高い**。

R78自体は周波数軸の表示点数を増やしただけで、MTF計算に使うray数やPSFヒストグラムの解像度には触れていない。したがって、R78が原因でこの振動を「発生させた」わけではなく、**元々存在していた計算上の問題を、点数を増やしたことで可視化しただけ**という可能性が高い。ただし、これは推測であり、実データで確認すること。

## 作業

### 1. 現状確認

1. 現行のMTF APIが幾何PSFを計算する際に使用しているray数・PSFヒストグラムの解像度（グリッドサイズ、ピクセルサイズ等）を、実装コードとAPIレスポンスのmetadataで確認する。
2. これがUIの共有`ray_sampling`設定（既定9 rays等）からそのまま渡されているのか、MTF専用の内部設定があるのかを確認する。
3. P002について、ray数を変化させながら（例：9、100、1000、4096、10000、100000）同一条件でMTFを計算し、周波数ごとの値の変化を実測する。振動・中域回復が、ray数を増やすことで解消・軽減するかを確認する。
4. 振動の原因がray数不足によるPSFヒストグラムのノイズであることを、周波数領域での理論的な妥当性（例：単純な球面収差主体のレンズでは、幾何MTFは通常滑らかに減衰し、収差の影響で多少の波打ちはあっても、大きく1.0近くまで回復するような形状にはならないこと）と合わせて確認する。

### 2. 修正

1. 現状確認の結果、ray数不足が原因と判明した場合、周辺光量（R75作業2）と同様に、MTF計算（幾何PSF算出）に使うray数をUIの共有`ray_sampling`設定から独立させ、`doc/engine_spec.md` 20.2節が推奨する範囲（4096〜100000 rays/field）に収まる適切なデフォルト値へ変更する。
2. 修正後、P002のMTFカーブが振動・不自然な回復のない、物理的に妥当な滑らかな減衰形状になることを、修正前後の実測値・スクリーンショットで示す。
3. 既存の推奨fieldでの近軸値・EFL・F値等が変化しないことを確認する。
4. R71の30秒性能ガード、R78で追加した33点の周波数サンプリングとの組み合わせでも許容時間内に収まることを確認する。
5. white MTF（R73作業3）にも同様の修正を適用する。

## 完了条件

- MTF計算に使われているray数・PSFヒストグラム解像度が、コード・APIレスポンスで確認され、報告書に明記されている。
- 振動・中域回復の原因がray数不足であるかどうかが、複数ray数での実測比較により結論付けられている（原因が別にある場合はその内容を明記する）。
- 修正した場合、P002・他の代表プリセットで、修正前後のMTFカーブが数値・スクリーンショットで比較され、物理的に妥当な形状になっていることが示されている。
- 近軸値・EFL・F値等の既存値に影響がないことを確認している。
- R71の30秒性能ガードとR78の33点サンプリングとの組み合わせで許容時間内に収まることを確認している。
