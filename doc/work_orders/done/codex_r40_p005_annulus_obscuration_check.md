# P005：annulus中央遮蔽（副鏡遮蔽）が機能しているか確認 指示書（Codex向け）

## 背景

人間が実際にP005（同軸カセグレン望遠鏡）のLayout Viewをブラウザで確認したところ、以下の点が気になった：

1. STOP要素がレイアウト図上に見当たらない（凡例には項目があるが、実際の描画に見えない）。
2. 光線束がM2（副鏡）の中心付近からも出ているように見え、カセグレン特有の中央遮蔽（副鏡による環状遮蔽、ドーナツ状の入射光束）が視覚的に確認できない。
3. M1〜M2〜IMG間の光線の角度変化が緩やかに見え、主鏡・副鏡それぞれでの強い収束が表現されていないように見える。

エンジン仕様6.3節・6.4節では、カセグレン系の中央遮蔽をannulus絞り形状（inner/outer半径）で表現する設計になっている。

## 作業

1. **P005の実際のsystem定義を確認する**：STOP要素（開口絞り）が定義されているか、annulus形状（inner_semi_diameter_mm/outer_semi_diameter_mm）を持っているか確認する。定義が存在しない場合、そのことを明確に報告する。
2. STOP要素が存在する場合、Layout View上になぜ表示されていないか確認する（描画対象から漏れている、位置が画面外、等）。
3. 実際にトレースされた光線群のデータ（絞り面通過点のY座標）を確認し、annulus遮蔽が機能していれば「inner半径より内側を通る光線が存在しない」はずである。これを検証する。機能していなければ、その原因を特定する（絞り定義自体が無い、annulus判定ロジックが呼ばれていない等）。
4. 光線の角度変化について、近軸トレース結果（M1・M2それぞれでの近軸光線の傾き変化）を確認し、実際の光線経路の傾きと整合しているか確認する（仕様6.3節の検算例：y=100,u=0→M1後u=-0.1→M2位置y=35→M2後u=-0.0333、という近軸挙動と、実際の描画上の角度変化が定性的に一致するか）。
5. 上記の結果を踏まえ、以下のいずれかを特定して報告する：
   - (a) STOP・annulus定義自体がP005のプリセットに存在しない（実装漏れ）。
   - (b) 定義は存在するが、Layout View描画または光線生成のどちらかでannulus判定が正しく適用されていない（バグ）。
   - (c) 実際には正しく機能しているが、見た目上わかりにくいだけ（例えば中央遮蔽の範囲が小さく、視覚的に目立たない）。
6. 原因に応じて修正する。(a)の場合はannulus絞り定義をP005プリセットに追加する。(b)の場合は該当ロジックを修正する。(c)の場合は視覚的にわかりやすくする調整を検討する（過剰実装は避ける）。

## 完了条件

- annulus中央遮蔽の実装状況（存在有無、機能有無）が明確に報告されている。
- 問題があれば修正され、P005のLayout Viewで中央遮蔽が視覚的に確認できる（光線束が中央付近を避けて環状に分布する）。
- STOPマーカーがLayout View上に表示される（または非表示である理由が報告される）。
- 近軸挙動との整合性が確認されている。
- 完了報告前にプロセスを再起動し、`build_info.git_commit`がHEADと一致することを確認し、断定形で報告に記載する（未来形で締めない）。
