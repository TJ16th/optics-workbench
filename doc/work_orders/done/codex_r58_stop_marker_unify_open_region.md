# R58：STOP断面表現の統一（開口部＝線がある、で一貫させる） 指示書（Codex向け）

## 背景

人間が2種類のプリセットのLayout Viewスクリーンショットを見比べたところ、STOP系マーカーの描画規約が食い違っている疑いが見つかった。

- 通常の円形STOP（例：P001系）：光軸（Y=0）から半径位置（Y=semi_diameter）まで**連続する1本の線**が描かれているように見える。これは「線がある区間＝光が通る開口部」という読み方ができる。
- Annulus STOP（P005）：R54/R57で導入した現行実装は、内径Y=±inner・外径Y=±outerの4箇所に、それぞれ**高さ10pxの独立した短いティックマーク**を置くだけで、内径〜外径の間（実際に光が通る環状の帯）を結ぶ線は描かれていない。

人間から「開口部は線がある、で統一した場合、問題は起きるか」という確認があり、AI（Claude）の予備検討では以下の論点が挙がった。

1. 通常の円形STOPは「inner=0のannulus」とみなせるため、統一ルール（内径〜外径の間を線で結ぶ）に一本化しても矛盾しない。むしろcircle用・annulus用で描画ロジックが分かれている現状を整理できる可能性がある。
2. 内径と外径がほぼ等しい薄いannulusでは、物理的に正確な長さで線を引くと表示上1px未満になり視認できなくなるおそれがある。最低表示長の確保が必要か検討する。
3. STOP位置はmarginal rayが密集して通過する箇所でもあるため、線を延長すると光線との重なりが増える可能性がある。色・線種で判別可能かを画面で確認する。
4. R49（開口輪郭形状の拡張、backlog登録のみで未実装）を見据え、円・annulus以外の形状が将来追加されても破綻しにくい一般化ができるとなお良い（ただし本タスクでの新形状対応は範囲外）。

## 作業

### 1. 現状の実装確認

1. 通常の円形STOPの描画コードを確認し、実際に「軸から半径位置まで連続する1本の線」という理解が正しいか確認する（人間の目視のみに基づく仮説であり、断定されていない）。
2. Annulus STOPの現行描画コード（R54/R57で修正した箇所）を確認し、「4本の独立した10pxティック」という理解が正しいか確認する。
3. 上記2つが実際に異なる描画方式であることをコードレベルで確認する（もし既に統一されていた、または人間の目視誤認だった場合は、その旨を報告し本タスクを完了扱いとしてよい）。

### 2. 統一ルールの設計・実装

1. 「その面のX位置において、実際に光が透過しうるYの区間に対してのみ線を引く」という単一ルールに統一する。
   - 通常の円形STOP（inner=0相当）：Y=0〜+semi_diameter、Y=0〜-semi_diameterの2本（＝実質、軸を挟んで対称な1本の連続線として見える）。
   - Annulus STOP：Y=+inner〜+outer、Y=-outer〜-innerの2本（内径〜外径の間の帯を直接結ぶ線）。
2. circle・annulusを同一の描画ロジック（inner=0を許容する一般化された関数）で扱えないか検討し、可能であれば一本化する。難しい場合は理由を報告する。
3. **最低表示長の扱いを決める**：inner〜outerのmm換算pxが極端に小さい（例：数px未満）場合に、視認性のためどこまで最低表示長を確保するか方針を決めて実装する。方針例：物理的な位置（中心Y）は正確な換算値のまま、線の長さのみ最低Nピクセルを下限として拡張する。採用した方針と数値根拠を報告に明記する。
4. STOP系のマーカー色・線種が、光線（chief/marginal/density）や他の面線（cemented/reflecting surface等）と視覚的に判別できることを、実際のスクリーンショットで確認する。
5. 凡例のアイコンも新しい描画方式に合わせて更新する。

## スコープ外

- R49の新規開口形状（円・annulus以外）の実装そのものは行わない。今回の一般化がそれを妨げないことの確認に留める。
- circle・annulusの物理的な半径値・スケール計算ロジック自体（R53/R54で確立済み）は変更しない。

## 完了条件

- 通常の円形STOP・Annulus STOPの双方が、同一の描画ルール（開口部＝実際に線がある区間）で表現されていることを、コードとDOM実測の両方で確認・報告している。
- 少なくとも通常円形STOPを含むプリセット（例：P001）とP005（annulus）の両方で、実DOM/SVGの座標を計測し、それぞれのsemi_diameter/inner/outerのmm値と整合していることを数値で示している。
- 円形STOPの見た目が本タスクの前後で意図せず変化していないこと（回帰確認）。
- 最低表示長の方針と、採用した具体的な数値・根拠が報告に明記されている。
- 凡例アイコンが新しい描画方式と一致している。
- 修正後のスクリーンショット（少なくとも1つの円形STOP系プリセット、1つのannulus系プリセット）が`doc/reports/screenshots/`に保存され、報告書から参照される。
- 既存テストがグリーン。関連する回帰テストが新しい描画方式に合わせて更新されている。
- 完了報告前にプロセスを再起動し、`build_info.git_commit`がHEADと一致することを断定形で記載する（未来形で締めない）。
- **完了報告の「実装根拠」には、コミットメッセージだけでなく実際のコミットハッシュ値（短縮形・完全形どちらか、可能なら両方）を必ず併記する。**

## 注意

- 目視の印象だけで「食い違っている」と決めつけず、まず実コードで通常STOPとannulus STOPの現行描画ロジックを確認してから着手すること。もし既に一貫していた場合は、無理に変更せずその旨を報告すること。
- R54で「過剰な装飾は避ける」として見送られた「内径〜外径間の帯を線で示す」という選択肢を、今回はより積極的に採用する方向で検討してよい（今回の目的は視認性ではなく規約の一貫性であるため）。
