# R53：annulusマーカーサイズの数値検証／ミラー自体の遮光仕様の確認 指示書（Codex向け）

## 背景

R51後のスクリーンショットについて、人間から「annulus絞りのマーカー（黄色い輪）とM2の弧のサイズが視覚的に釣り合って見える」というAI（Claude）の評価に対し、「よく分からない」という指摘があった。この評価は実際にピクセル寸法を測定したものではなく、目視の印象で述べたものであり、不正確である可能性がある。

また、人間から「ミラーは基本的にそれ自体が遮光機能を持つという仕様であっているか」という確認があった。

## 作業

### 1. annulusマーカーとM2弧のサイズの数値検証

1. Layout ViewのSVG（またはそれに相当する描画データ）から、実際に描画されている以下2つの寸法を、ピクセル単位またはmm換算で取得する：
   - annulus絞りマーカー（STOPマーカー、内径・外径の輪）の半径。
   - M2の弧の描画範囲（Y方向の最大到達距離、光軸からの半径相当）。
2. 両者が実際に一致している（M2の描画半径 = annulusのinner半径相当のスケール）か、数値で確認する。目視ではなく、SVG座標またはmm換算値で比較すること。
3. 一致していなければ、どちらの描画が誤っているか（annulusマーカーのスケール変換、またはM2弧の半径参照）を特定し、修正する。

### 2. ミラー自体の遮光仕様の確認（仕様整理）

1. エンジン仕様17.3節（有効径判定）を確認し、以下を明確にする：
   - 「その面自身の有効半径（`semi_diameter_mm`）を超える光線を遮光する」という判定は、`kind: mirror`を含む全ての面種別に適用される「外径側」の遮光であること。
   - これは「ミラー自体が遮光機能を持つ」という理解と一致することを確認する。
2. 一方、「内径側」の遮光（annulusのような、中心付近を遮る）は、現状では専用のannulus絞り面（別途配置する面）によってのみ実現されており、ミラー面自身の有効径からは自動的に導出されないことを確認する。
3. R49の②-a（実体を持つ後続面自体による内径遮蔽の自然な表現）は、この「ミラー面自身が内径遮蔽の原因にもなれるようにする」という拡張を提案したものであり、**現時点ではまだ実装されていない**（P005のannulus絞りは、R47の修正後も依然として専用面として存在している）ことを、完了報告で明確に述べる。
4. 上記の整理を`doc/engine_spec.md` 17.3節に、以下のような形で一言補足することを検討する（過剰な記述は避ける）：
   - 「面の有効径判定は外径側の遮光のみを扱う。内径側（中央）の遮光が必要な場合はannulus形状の絞り面を別途配置する（将来的にミラー等の面自身から内径遮蔽を導出する拡張は検討中、Issueバックログ参照）」

## 完了条件

- annulusマーカーとM2弧のサイズが、目視ではなく実際の数値（ピクセルまたはmm換算）で比較され、一致または不一致が報告されている。不一致であれば修正されている。
- 「ミラー自体は外径側の遮光機能を持つが、内径側の遮光（annulus的な中央遮蔽）は専用面に依存している」という現状仕様が明確に確認・報告されている。
- 必要であれば`doc/engine_spec.md`への軽微な補足が行われている。
- 完了報告前にプロセスを再起動し、`build_info.git_commit`がHEADと一致することを確認し、断定形で報告に記載する（未来形で締めない）。

## 注意

作業1は、AI（Claude）が目視のみで「釣り合って見える」と判断したことへの検証依頼である。目視の印象を報告するのではなく、必ず実際の数値（座標・半径）を取得して比較すること。
