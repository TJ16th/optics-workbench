# 7割像高field・評価値の組み込み 指示書（Codex向け）

## 背景

人間から「7割像高（0.7×最大像高相当のfield）の表示・評価値への組み込みを追加したい」という要望があった。7割像高は写真レンズの実務評価で標準的に使われる代表点（中心・7割像高・周辺の3点で収差傾向を確認する慣習）。

R37でプリセットへの推奨field付与を実装済みであれば、その推奨fieldセットに7割像高相当のfieldを含めることで、本タスクの目的の大部分を達成できる可能性が高い。

## 作業

1. R37の実装内容を確認する。プリセットの推奨fieldセットが「中心・中間・周辺」の3点程度である場合、その「中間」が7割像高相当の画角になっているか確認する。
2. なっていなければ、各プリセットの推奨fieldセットに7割像高相当のfieldを追加する。7割像高の算出方法：
   - 最大画角（周辺field）の理論像高 `h_max = f・tan(θ_max)`（仕様21.3節）を求める。
   - 7割像高 `h_70 = 0.7 * h_max` に対応する画角 `θ_70 = atan(h_70 / f)` を算出する。
   - 単純に画角を0.7倍するのではなく、像高ベースで7割を計算すること（tanの非線形性のため、画角の0.7倍と像高の7割は広角レンズで乖離しうる）。
3. 評価値（spot、MTF等）のfield一覧に、7割像高fieldを含めることで、既存の評価APIがそのまま7割像高での評価値を返せることを確認する（新規APIは不要なはずだが、確認する）。
4. UI上で、fieldリストに「70%像高」等、わかりやすいラベルを付ける（i18n対応）。

## 完了条件

- 各プリセット（afocal系P006を除く、または適切な代替指標があれば含める）の推奨fieldセットに7割像高相当のfieldが含まれる。
- 7割像高の算出が画角の単純比率ではなく像高ベースで行われている。
- UIで7割像高fieldがラベル付きで識別できる。
- 既存テストがグリーン、新規テストが追加されている。
- 完了報告前にプロセスを再起動し、`build_info.git_commit`がHEADと一致することを確認し、断定形で報告に記載する（未来形で締めない）。
