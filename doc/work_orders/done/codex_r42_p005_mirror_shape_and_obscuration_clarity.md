# P005：物体側光線の欠落、M2形状未描画、annulus配置の光学的妥当性 指示書（Codex向け）

## 背景

人間がP005（カセグレン）で「サンプル光線を表示」をオフにし、baseline layer（chief/marginal ray）のみで確認したところ、3点の問題が見つかった。

1. marginal ray（破線）がM2の位置で唐突に始まっており、それより物体側（無限遠方向）の入射光束が描画されていない。
2. M2（副鏡）が単なる縦線（面位置マーカー）として描かれており、R40/R41で修正したM1のような曲率を持つ反射面としての形状表現がない。
3. STOP（annulus絞り）がM1の直前に配置されているが、これが実際のカセグレン式望遠鏡の物理構成（主鏡M1に開口があり、副鏡M2は通常の円形凸面鏡である、という標準構成）を正しく反映しているか不明瞭。annulus遮蔽がどの要素の物理的な形状を表現しているのかが、見た目から判断できない。

## 作業

### 1. 物体側光線の欠落確認

1. R11（レイアウト図の光線描画範囲）で実装した「物体側への固定距離延長描画」が、ミラー系（P005のようにpropagation_signの反転を伴う系）でも機能しているか確認する。
2. 機能していない場合、原因を特定する（ミラー系特有の座標変換で、物体側延長のロジックが正しく適用されていない可能性がある）。
3. 修正し、M2より物体側（望遠鏡の場合は入射開口の手前）に、無限遠物点からの平行光束が描画されることを確認する。

### 2. ミラー面（M1・M2）の形状描画確認

1. UI仕様17章のミラー描画規約（「ミラーは反射面らしい表現」）が実際に実装されているか確認する。
2. 現状M1・M2が単なる縦線として描かれている場合、これが意図的な簡略表示なのか、実装未対応なのか確認する。
3. 未対応であれば、ミラー面に曲率（`radius_mm`）を反映した弧を描画する対応を検討する。過剰な作り込みは避け、レンズと同様の弧描画ロジックを反射面にも適用する形で、最小限の対応でよい。屈折面と反射面が視覚的に区別できるよう、色または線種を変える（凡例にも反映する）。

### 2b. 反射角の物理的正しさの検証（追加・重要）

人間から「ミラーの曲率と、光線の反射角も合っていなさそうに見える」という指摘があった。これは描画上の簡略化（M1が縦線で描かれている）だけの問題ではなく、**光線追跡の計算自体がM1・M2の曲率を正しく反映して反射角を計算しているか**という、より根本的な検証が必要であることを示す。座標（位置）が近軸検証値と一致することはR40/R41で確認済みだが、個々の光線の反射角（方向ベクトル）はまだ検証していない。

1. P005の主光線（chief ray）について、M1到達直前の入射方向ベクトルと、M1到達直後の反射方向ベクトルを取得する。
2. Snellの法則の反射版（仕様13.3節：`R = I - 2*dot(I,N)*N`）に基づき、M1の面法線（`radius_mm=-2000`の凹面、その面上の光線到達点における法線）を計算し、上記の入射・反射方向ベクトルがこの式を満たしているか手計算またはスクリプトで検証する。
3. M2についても同様に検証する。
4. 近軸トレース結果（仕様6.3節の検算：M1後u=-0.1、M2後u=-0.0333）と、実光線トレースの角度が定性的に整合しているか確認する。
5. 不一致があれば、これは描画の問題ではなく光線追跡の計算ロジック自体のバグである。最優先で原因を特定し修正する。作業2（ミラー形状描画）より優先して対応すること。

### 3. annulus配置の光学的妥当性確認

1. 現在P005で、annulus絞り（STOP）がどの面として、どの位置に配置されているか正確に確認する（M1の前か、M2の位置と重ねているか等）。
2. 実際のカセグレン式望遠鏡の標準構成（主鏡M1の中央に開口があり、そこから像を取り出す。副鏡M2は中央に開口を持たない通常の凸面鏡）と、現在のP005の構成を比較する。
3. 現在の構成が物理的に何を表現しているか（副鏡M2による中央遮蔽を、別のSTOP面でモデル化しているのか、主鏡M1の中央開口を表現しているのか）を明確にし、報告する。
4. 現在の表現が紛らわしい場合、以下を検討する：
   - annulus絞りの面ラベル・ヘルプ（ツールチップ）に「これは副鏡M2による中央遮蔽を表現する仮想的な絞り面である」等の説明を追加する。
   - 可能であれば、M2の描画（作業2の対応後）とSTOP（annulus）の視覚的な関連が分かるようにする（例えばSTOPをM2の位置に近づける、または線で関連を示す等、過剰にならない範囲で）。
5. 対応方針を報告する（大規模な再設計はせず、説明の追加や軽微な視覚調整に留める）。

## 完了条件

- 物体側の入射光束が正しく描画される。
- **M1・M2での反射がSnellの法則（反射式）を満たしていることが数値で検証されている。不一致があれば計算ロジックが修正されている。**
- ミラー面（M1・M2）が曲率を反映した弧として描画され、屈折面と視覚的に区別できる。凡例にも反映される。
- annulus絞りが物理的に何を表現しているかが明確になり、ユーザーにも伝わる形（ラベル・ヘルプ等）になっている。
- 完了報告前にプロセスを再起動し、`build_info.git_commit`がHEADと一致することを確認し、断定形で報告に記載する（未来形で締めない）。

## 注意

本タスクは調査の性質が強い（特に2bと3は、実装変更が必要かどうかもこのタスクで判断する）。**作業2bを最優先で行う**（もし反射角自体に計算ロジックのバグがあれば、これは他の項目より深刻な問題であり、Golden Testの信頼性にも関わる可能性があるため）。2bで異常が見つからなければ、続けて1・2・3を番号順に進める。各項目の現状確認結果を先に報告してから対応方針を決めること。
