# R81：P011中心spot RMSの微小決定論的ずれ 原因調査 指示書（Codex向け）

## 背景

R80完了報告（作業3）で、既存のP011直接回帰テスト（`tests/test_preset_api_smoke.py::test_p011_planar_double_gauss_has_six_positive_thickness_elements`）の中心81-ray spot RMSが、期待値`0.46542296012362827 mm`（R67導入時の基準値、コミット`92c88b4`）に対し、現行HEAD（`1031997`、直近機能コミット`b655a3a`＝R79）で`0.46544749658602347 mm`を**決定論的に**返し、2回とも同じ値で失敗することが判明した。差は約`2.45e-5 mm`（5桁目）。

R80の調査時点では、P011の処方定義・trace関連コードにR67のコミット`92c88b4`以降の差分が見当たらないと報告されているが、実際に値が変わっている以上、`92c88b4`から現行HEADまでの間のどこかのコミットが、直接・間接を問わずこの計算結果に影響している。乱数やタイミング依存ではなく決定論的に再現するため、環境ノイズではなく実際のコード変化によるものである可能性が高い。

この期間には、R73（軸上瞳中心点のセンサー位置誤代入修正、コミット`1afa3a9`）、R75（像面湾曲へのCoddington方程式実装）等、エンジン側のray tracing・aiming・近軸計算に関わる修正が複数含まれている。**どのコミットが原因かは断定されておらず、推測で決め打ちせず実際に特定すること。**

## 作業

### 1. 原因コミットの特定

1. `92c88b4`（R67導入時、期待値`0.46542296012362827 mm`を記録した時点）から現行HEADまでの間で、P011の中心81-ray spot RMS値（またはそれに相当する最小再現スクリプト）を、関連するエンジン側コミットごとに計算し、値がどのコミットで変化したかを特定する（`git bisect`または該当コミットの手動チェックアウトのいずれでもよい）。
2. UI側のみの変更（表示・サンプリングデフォルト等、エンジン計算式に触れないもの）は候補から除外してよいが、除外の判断根拠を明記する。
3. 原因コミットを特定したら、そのコミットの変更内容が具体的にどのコード経路でP011のfull aiming結果に影響しているかを、コード差分と実際の中間計算値（例：aiming反復回数、収束後のpupil座標、交点座標等）で示す。

### 2. 変化の性質の判定

1. 特定した変更が「意図した修正の正当な副作用」（例：以前は間違った値を返していて今回正しくなった）なのか、「意図しない退行」なのか、「数値精度・収束判定の閾値変更等による誤差範囲内の揺れ」なのかを判定する。
2. 判定の根拠として、Level 0相当のリファレンス計算（近軸予測、または独立した外部検証手段があれば併用）との比較を可能な範囲で行う。R67時点の値・現行値のどちらがより物理的に正しいか、あるいは両者とも許容誤差内かを明らかにする。

### 3. 影響範囲の確認

1. 同じ原因コミットが、P011以外のプリセット（特にfull aimingを使う既存回帰テストがあるプリセット）の既存期待値にも同程度の影響を与えていないかを確認する。既存テストスイート全体が現在グリーンであること自体は既知だが、それは「既存テストの許容誤差内に収まっている」だけの可能性があるため、可能なら複数プリセットで同条件のspot RMSをR67相当の古いコミットと現行HEADとで比較し、差分の有無・大きさを実測する。
2. 影響が P011 単体に留まるのか、full aimingを使う系全般に及ぶ僅かな挙動変化なのかを結論付ける。

## 完了条件

- 原因コミットのハッシュが特定され、そのコミットが何を変更したことでP011の中心spot RMSに影響したかがコード差分と中間計算値で説明されている。
- 変化が「正当な修正の結果」「意図しない退行」「許容誤差内の揺れ」のいずれであるかが、リファレンス比較を含む根拠とともに判定されている。
- P011以外のプリセットへの影響有無が、複数プリセットでの実測比較により確認されている。
- 本タスクでは実装修正は行わない（原因調査のみ）。修正が必要と判明した場合は、修正方針・規模感（小/中/大）と、P011の既存backlog Issue（aiming_failed 12件）との関係整理を報告書に記載するに留める。
- 完了報告に、比較に使った具体的なコミットハッシュ・実測値を全て明記する。

## 注意

- 「原因はおそらくこのコミット」という推測で終わらせず、実際にコミットを切り替えて数値を確認すること。
- P011のaiming_failed 12件（既存backlog Issue）の修正は本タスクの対象外。関連性が見つかった場合のみ、その関連性を報告書に記載する。
- 本タスクは調査のみであり、既存テストの期待値更新・コード修正は行わない。
