# R42後続：M2曲率符号の誤り／Annulus STOPマーカーの表示不整合 再調査 指示書（Codex向け）

## 背景

R42完了後、人間が実際にブラウザで確認したところ、まだ2点の問題が残っている。

1. **M2の曲率が物理的に不自然**：M1（主鏡、凹面）とM2（副鏡）が、画像上**同じ向き（どちらも左側に凹んだ弧）**で描かれている。カセグレン式望遠鏡の副鏡M2は、主鏡に向かって凸面（M1とは逆向きに膨らむ形状）であるべきである。曲率の符号（凹凸の向き）が正しく反映されていない可能性が高い。
2. **凡例とレイアウト図の不整合**：凡例に「STOP」（塗りつぶし丸）と「Annulus STOP（副鏡による中央遮蔽）」（輪郭丸）の2種類のマーカーが追加されているが、実際のレイアウト図にはオレンジの塗りつぶし丸が1つしか見えず、Annulus STOP用の輪郭マーカーが表示されていない。

## 作業

### 1. M2曲率の符号確認（最優先、推測で直さない）

1. P005のsystem定義におけるM2の`radius_mm`の実際の値（符号含む）を確認する。
2. R42で追加したミラー弧描画ロジックが、この`radius_mm`の符号をどう解釈して弧の向きを決定しているか、コードを確認する。
3. 仕様5.1節の符号規約（R>0は曲率中心が+X側、R<0は-X側）と、ミラー系特有の座標変換（propagation_sign反転）を踏まえ、M2の弧の向きが正しく計算されているか検証する。単純な符号の取り違え（レンズ用の描画ロジックをそのままミラーに流用し、反射後の座標系での符号解釈を考慮していない等）が無いか確認する。
4. R42で実施した反射角のSnell法則検証（数値的には正しいことを確認済み）と、今回の描画上の曲率符号の話は別レイヤーの問題である可能性が高い（計算は正しいが描画だけが誤っている、または逆）ことに留意し、切り分けて調査する。
5. 原因を特定し修正する。修正後、M1・M2が物理的に正しい凹凸関係（副鏡は主鏡に対して逆向きの曲率）で描画されることを確認する。

### 2. Annulus STOPマーカーの表示確認

1. 凡例に追加した「Annulus STOP（副鏡による中央遮蔽）」マーカーが、実際のレイアウト図のどの要素に対応する想定だったか確認する（STOP面自体の表現なのか、annulus遮蔽の視覚化なのか）。
2. なぜ実際のレイアウト図にこのマーカーが表示されていないか確認する（描画条件の見落とし、凡例だけ追加して実装が伴っていない等）。
3. 原因を特定し、実際にannulus遮蔽（中央開口）が視覚的に確認できる形で描画されるよう修正する。R42の③の結論（主鏡M1の中央開口を表現）を踏まえ、M1の描画に穴（欠け）を反映する対応が必要であれば、これも本タスクで実施する。

## 完了条件

- M1・M2が物理的に正しい凹凸関係で描画される（副鏡は主鏡と逆向きの曲率）。スクリーンショットで確認する。
- Annulus STOPマーカーが凡例通りに実際のレイアウト図でも表示される、または凡例側を実態に合わせて修正する。
- 両問題について、原因（描画ロジックのバグか、実装未完了か）を明確に報告する。
- 完了報告前にプロセスを再起動し、`build_info.git_commit`がHEADと一致することを確認し、断定形で報告に記載する（未来形で締めない）。

## 注意

R42の完了報告では「ミラー面に曲率を反映した弧を追加した」「annulus絞りの配置を主鏡M1の中央開口として整理した」と記載されていたが、今回の人間による目視確認で、報告内容と実際の表示が一致していないことが判明した。**報告時点で実際にスクリーンショットを取得し目視確認していたか、それとも数値・コードの確認のみで完了と判断していたかを、完了報告に明記すること。** 今後、視覚的な変更を伴うタスクでは、コード上の実装確認だけでなく、実際のブラウザ描画のスクリーンショットを完了報告に添付することを徹底する。
