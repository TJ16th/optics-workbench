# 全プリセットの有効径（semi_diameter_mm）見直し 指示書（Codex向け）

## 背景

現在のプリセット（P001〜P007）の各面`semi_diameter_mm`は、多くが仮置きの丸め値（設計時にキリの良い数値を当てただけ）になっており、実際にその面を通過する最外殻光線（marginal ray）の高さに対して過剰なマージンを持っている可能性が高い。

エンジン仕様25.6節では、屈折面の`semi_diameter_mm`は最適化変数として「実際に通る光束＋必要マージン」まで絞り込む使い方を想定している。プリセットについても、教育目的（「レンズの形が実際のレンズらしく見える」）の観点から、過剰な有効径を実光束ベースの値に近づけたい。

## 作業

1. P001〜P007それぞれについて、各面の実際のmarginal ray到達高さ（絞り縁を通る光線の、その面での通過高さ）を、既存の近軸トレース・実光線トレースAPIで取得する。
2. 各面の`semi_diameter_mm`が、対応するmarginal ray高さに対してどの程度のマージン（%）を持っているか一覧化する。
3. マージンが過大（目安：実光束高さの30%を超える余裕がある等、判断して基準を決めてよい）な面を洗い出す。
4. 各プリセットの`semi_diameter_mm`を、実光束高さ＋妥当な安全マージン（目安5〜15%程度、面の種類・用途に応じて判断）に調整する。
5. 調整後、以下を確認する：
   - 近軸検証（EFL・BFL等）が変化していないこと（`semi_diameter_mm`の変更は光学的パワーには影響しないはずだが、念のため確認する）。
   - 意図した画角・fieldの光線がケラレずに通ること（有効径を絞りすぎて周辺光線が新たに`blocked`にならないよう注意する）。
   - Layout Viewでの見た目が、実際のレンズらしい形状（過剰な余白が無い）になっていることを確認する。
6. 特にP007（R28で調査対象になっているS1/S2の有効径差）は、R28の調査結果と合わせて本タスクで値を決定する。R28とR29（本タスク）のどちらが先に着手されても構わないが、両者の結論が矛盾しないよう、担当時点でもう一方の状況を確認すること。

## 完了条件

- P001〜P007全プリセットの各面`semi_diameter_mm`が、実光束高さに基づく妥当な値に調整されている。
- 調整前後の近軸量（EFL・BFL・F値）に変化がないことが確認されている。
- 調整後もケラレが意図せず発生していないことが確認されている（既存の受け入れ条件・E2Eで確認）。
- 調整の基準（マージンの決め方）が報告に明記されている。
- 完了報告前にプロセスを再起動し、`build_info.git_commit`がHEADと一致することを確認する（AGENTS.md規約通り）。
