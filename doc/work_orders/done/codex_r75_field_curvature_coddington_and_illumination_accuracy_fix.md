# R75：像面湾曲Coddington実装／周辺光量の精度・仕様不一致修正 指示書（Codex向け）

## 背景

R74（`2026-07-13_r74_task1_field_curvature_sampling_review.md`／`2026-07-13_r74_task2_relative_illumination_sampling_review.md`）の調査で、2件の実在の不具合が確定した。

1. **像面湾曲・M/S像面**：`doc/engine_spec.md` 21.2節は同軸系の既定をCoddington方程式（主光線1本＋各面の漸化式による解析計算）と定めるが、実装は常に内部固定`21 rays/grid/paraxial`のRMS探索を行っており、Coddington方程式は一度も実行されていない。にもかかわらずレスポンスの`method`は`coddington_rms_consistent`という誤ったラベルを返す。また、P003では全fieldでField Curvature shiftが探索範囲下端`-5.0mm`に張り付いており、範囲不足か収束済みかを区別する情報がない。
2. **周辺光量**：UIの共有`ray_sampling`（既定9 rays）がそのまま周辺光量エンドポイントへ渡っており、周辺光量専用の高サンプル数設定がない。部分ケラレが生じるfieldで、9 raysが100000 rays基準に対しrelative illuminationを11.68%過大評価することが実測で確認された。response metadataもサンプル数・distribution・aiming・重み付けを返さず、`doc/engine_spec.md` 16.5・21.4節の放射量定義・metadata要件と不一致。

R74作業4（自動収束サンプリング設計）は将来の本格対応として別途issues_backlog.mdへ登録済みだが、本タスクでは**適応サンプリングの実装は行わず**、上記2件の具体的な不具合修正に絞る。

## 作業1：像面湾曲・M/S像面のCoddington方程式実装

1. `doc/engine_spec.md` 21.2節の規定通り、同軸系（decenter/tiltなし）に対しては実際にCoddington方程式（主光線に沿った各面での微分光線追跡・漸化式）でメリディオナル・サジタル像点位置を解析的に求める実装を追加する。
2. 偏芯・チルト系では既存のRMS探索方式を維持する（21.2節の使い分け規約通り）。
3. レスポンスの`method`フィールドを、実際に使用した計算方式（`coddington`または`rms_search`等、実態と一致する値）へ修正する。誤ったラベル付けを解消する。
4. Coddington実装後、既存のRMS探索結果と相互検証する（21.2節が言及する「両方式の結果差は検証項目とする」に対応）。P002・P003で両方式の結果を突き合わせ、妥当な範囲で一致することを確認する。
5. RMS探索方式（偏芯・チルト系、または相互検証用）について、探索範囲端に結果が張り付いた場合（P003で発生した現象）に、非収束または範囲不足を示す警告をレスポンスへ追加する。
6. Coddington実装後、像面湾曲・M/S像面が`ray_sampling`条件に依存しないことを維持していることを確認する（元々サンプル数非依存だったことは変えない）。

## 作業2：周辺光量の精度・仕様整合修正

1. 周辺光量の計算に使うサンプル数を、UIの共有`ray_sampling`設定から独立させ、`doc/engine_spec.md` 20.2節が推奨する範囲（1000〜100000 rays/field）に収まる適切なデフォルト値を使うよう修正する。ユーザーがより高精度を求める場合に上書きできる余地は残してよい（適応サンプリングの実装自体は本タスクの対象外）。
2. response metadataへ、実際に使用したサンプル数・pupil distribution・ray aiming mode・重み付け方式を含める。`doc/engine_spec.md` 16.5節の放射量定義（等立体角サンプリングまたは数学的に等価な重み付け）との整合を明記する。
3. 修正後、R74作業2で確認された部分ケラレfield（例：P002の40 deg field）で、修正前の9 rays相当の結果と、修正後のデフォルト設定での結果を比較し、100000 rays基準との誤差が大幅に改善したことを数値で示す。
4. 既存の推奨field（ケラレのないrecommended field範囲）での結果が、修正前後で変化しないか、変化する場合はその差を明記する。
