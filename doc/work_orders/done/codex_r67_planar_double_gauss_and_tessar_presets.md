# R67：対称6枚ダブルガウス（Planar/Xenon型）50mm F1.4・テッサー型50mm F2.8プリセット新設 指示書（Codex向け）

## 背景

R66でP004として「対称8面・単玉4枚・非接合」構成のダブルガウス風50mm F1.4プリセットを実装済み（EFL 49.978mm、F/1.408、報告書`2026-07-13_r66_hide_p005_semidiameter_recheck_and_double_gauss_f14.md`）。

R66完了後、人間から改めて構成図（前群＝メニスカス単玉+接合ダブレット、STOP、後群＝接合ダブレット+メニスカス単玉、という対称6枚構成）が示され、「この対称6枚タイプの光学系で50/1.4もプリセットに入れたい」との要望があった。これは古典的な高速ダブルガウス（Zeiss Planar、Schneider Xenon等に代表される、前後2群ずつ・各群が接合ダブレットを含む6枚構成）であり、R66で実装したP004（単玉4枚・非接合）とは異なるレンズ群構成である。**両者は別物として扱い、P004は変更せず、新規プリセットとして追加する。**

あわせて人間から「テッサーも」という要望があった。テッサー型（4枚3群：前群＝単玉+単玉の空気間隔ペア、STOP、後群＝接合ダブレット）は写真レンズの古典設計だが、球面収差補正能力の制約からF1.4のような大口径には向かない。人間に確認したところ、F値は**F2.8**を指定された。

## 作業A：対称6枚ダブルガウス（Planar/Xenon型）50mm F1.4プリセットの新設

1. 現在コード上の最終プリセット番号を確認し、次の番号（想定P011。実装前に必ずコードで再確認すること）で新規プリセットを追加する。
2. 構成は以下のトポロジーとする（人間提示の構成図に基づく、古典的な高速ダブルガウスの標準形）。

   - 群1：メニスカス単玉（物体側に凸）
   - 群2：接合ダブレット（クラウン系+フリント系ガラス、STOP側が凹面で終わる構成）
   - STOP
   - 群3：接合ダブレット（群2とほぼ対称、STOP側が凹面で始まる構成）
   - 群4：メニスカス単玉（像側に凸、群1とほぼ対称）

   計6枚・8〜10面程度（接合面は1面としてカウント）。厳密な対称でなくてよいが、前後群のガラス選定・パワー配分は対称的な設計とすること。
3. 近軸計算でEFL≒50mm、F値≒1.4を目標に曲率・厚み・ガラス（N-BK7/N-F2等、既存プリセットで使用実績のある硝材を優先）を設計する。目標に対する達成度（一致／近似）と、達成できない場合の理由を報告書に数値で明記すること。
4. 全ての面のedge thicknessが正であることを確認する（負厚は不可、R63/R66と同様の物理的妥当性チェック）。
5. 有効径（semi_diameter）はR66作業2で確立した方法論（開口一時開放+実光線追跡で最大到達半径を実測し、+10〜12%程度のマージンを載せて0.25mm単位に丸める）を設計段階から適用する。
6. 近軸トレースと実光線追跡の両方で検証し、EFL・F値・BFL・center/mid/edge fieldでの実光線到達率（alive数、aiming_failed数、blocked数）を報告書に数値で明記する。
7. spot diagram・MTF・distortion・field curvatureが表示可能なことを確認し、可能であればP004（単玉4枚版）とのspot RMS比較を示す（接合ダブレットの色収差補正効果が数値で見えると望ましいが、必須ではない）。
8. Layout Viewのスクリーンショットを取得し、6枚の群構成が視覚的に確認できることを示す。

## 作業B：テッサー型50mm F2.8プリセットの新設

1. 作業Aの次の番号（想定P012。実装前に必ずコードで再確認すること）で新規プリセットを追加する。
2. 構成は古典的なテッサー型（4枚3群）とする。

   - 群1：単玉（前群、物体側に凸）
   - 群2：単玉（前群、群1とわずかな空気間隔）
   - STOP
   - 群3：接合ダブレット（後群、クラウン系+フリント系ガラス）

   計4枚3群。
3. 近軸計算でEFL≒50mm、F値≒2.8を目標に設計する。達成度を報告書に数値で明記する。
4. 作業Aと同様に、edge thickness正・有効径方法論（実測+10〜12%マージン）・近軸/実光線両方の検証・field別alive数・spot/MTF/distortion/field curvature表示確認・Layout Viewスクリーンショットを行う。

## 注意

- P004（R66で実装済みの単玉4枚版ダブルガウス）は変更しない。作業Aの6枚版は別プリセットとして共存させる。
