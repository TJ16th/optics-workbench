# Layout View：LOD光線サンプリングの対称性確認 指示書（Codex向け）

## 背景

Q1（Layout View描画品質改善）でLayout Viewの表示光線数をLOD化し、全光線ではなく代表pupil sampleのみを描画するようにした（P003で81本→27本）。しかし人間がブラウザで実際に確認したところ、**光束が絞りの上側からしか出ていないように見え、業界標準の断面図（上下対称に光線が描かれる）と比べて非対称で不自然**という指摘があった。一般的なレンズ断面図の作例では、複数fieldの光線が絞りの上端・下端の両方を通り、像側で対称に収束・交差する（詳細は末尾の「参考」節）。

## 作業

1. **原因調査（推測で直さない）**：現在のLOD代表サンプル選択ロジックを確認する。
   - 瞳サンプリング自体（エンジン側が返す光線群）は絞りの上下に対称に分布しているか、実際のレスポンスデータで確認する。
   - LOD処理（27本を選ぶ際の間引きロジック）が、対称性を保たずに偏った部分集合を選んでいないか確認する。
   - fieldの選択（軸上center・軸外upper/lower等）が、表示対象として均等に含まれているか確認する。P003で実際に評価されているfield一覧と、LOD後に表示されているfieldの対応を確認する。
2. 原因を特定した上で修正する。修正方針の例：
   - LOD選択を「瞳の対称な代表点（例：上端・下端・中心）を必ず含む」ように変更する。
   - 複数fieldがある場合、各field从均等に代表光線を選ぶ（1つのfieldに偏らない）。
3. 添付の参考画像のように、絞りの上下両方から光線が出て、レンズ通過後に像側で交差・収束する様子が視覚的に確認できることを目標とする。厳密に参考画像と同じ本数・構成である必要はないが、上下対称性と複数fieldの表示は満たすこと。
4. P002・P003両方で修正後の見た目を確認し、スクリーンショットを報告する。
5. 対称性を検証する軽いテスト（例：表示される光線群のY座標分布が絞り中心に対して概ね対称であることを確認する）を追加する。

## 完了条件

- P002・P003のLayout Viewで、光線束が絞りの上下両方から対称に出て、像側で収束する様子が視覚的に確認できる。
- 原因（瞳サンプリング自体の偏りか、LOD選択ロジックの偏りか、field選択の偏りか）が特定され、報告されている。
- 対称性を確認するテストが追加されている。
- 完了報告前にプロセスを再起動し、`build_info.git_commit`がHEADと一致することを確認する（AGENTS.md規約通り）。

## 参考（業界標準のレンズ断面図が持つ特徴）

一般的なレンズ設計ソフトが出力するレンズ断面図（外部サイト例：photo-china.net等の作例）は、以下の特徴を持つ。本タスクではこれらの特徴、特に**上下対称性**を満たすことを目標とする（画像そのものの入手・添付は行わない。以下の記述で十分）。

- 絞り（または入射瞳）の上端・下端の両方を通る光線が描かれ、レンズ通過後に像側で1点（またはfieldごとに複数点）へ収束する。
- 複数のfield（軸上・複数の軸外画角）がそれぞれ別の色（多くは波長ではなく画角ごとに色分けする作例と、波長ごとに色分けする作例の両方が存在する）で描かれ、上下対称に配置される。
- 光軸を挟んで上下対称な光線束になっており、片側だけに偏った表示にはならない。
- 各fieldの光線束は、絞り位置で上下端・中心付近の代表的な瞳位置を通る数本程度で表現される（全光線を描くのではなく、代表本数で十分)。

本タスクでは、この「上下対称性」と「複数fieldの表現」を満たすことを主目標とする。波長ごとの色分けと画角ごとの色分けをどちらも同時に行うかは判断に委ねるが、既存の波長色規約（F=青系、d/e=緑黄系、C=赤系）との整合は維持すること。
