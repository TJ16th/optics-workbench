## Issue: アフォーカル系のアイポイントに眼球モデルを接続し、網膜結像として評価できるようにする

- ラベル案：`engine`
- 背景：現行のafocal系評価（双眼鏡・望遠鏡）は、終端要素`eye_reference`（射出瞳・アイレリーフ・角度MTF等）までを評価対象とし、「眼に渡す角度像の品質」を間接的な指標で評価する設計（エンジン仕様9.2節・22章）。これに対し、眼球そのもの（角膜・水晶体・網膜相当）を簡易光学系としてモデル化し、`eye_reference`の後段に接続することで、実際の網膜結像（スポット・MTF）まで直接評価する手法を追加したいという提案があった。これは視覚光学（visual optics）分野で標準的に行われる評価手法で、実在の簡易模型眼（Gullstrand模型眼、Navarro模型眼等）を接続する形が想定される。
- 対応案：
  - まず標準的な模型眼（1つで良い、例えばGullstrand簡約模型眼）を、既存の`refractive`面・`sensor`（網膜相当）の組み合わせとしてプリセット化できるか検討する。
  - `system_type: afocal`の終端`eye_reference`の後段に、別の光学系（模型眼）を接続する仕組みが必要になる可能性が高い。現行のシステムモデル（`focal`/`afocal`の二択）にこの「afocal→focal接続」構成が無いため、仕様拡張の要否を検討する。
  - 眼球モデルの個人差（瞳孔径、屈折異常、調節状態）をどこまでパラメータ化するかを決める（初期版は固定の標準模型眼のみで良い）。
  - 双眼鏡・望遠鏡の既存評価値（射出瞳、角度MTF）との関係を整理し、責務の重複を避ける。
- 受け入れ条件：
  - （初期段階）標準模型眼を1つ、afocal系の後段に接続し、網膜相当面でのspot/MTFが評価できる。
  - 既存のafocal評価（射出瞳、角度MTF等）と矛盾しない。
  - 仕様拡張（afocal→focal接続の構成）が必要な場合、その設計方針が別途エンジン仕様改訂として文書化される。
