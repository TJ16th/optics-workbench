# Layout View：絞り・センサー記号の実寸反映確認 指示書（Codex向け）

## 着手タイミング

**Layout View描画品質改善（`codex_layout_view_rendering_quality.md`）がまだ進行中であれば、このタスクを同時に含めて対応してよい**（同じ描画コンポーネントを扱うため）。既に完了報告済みであれば、次点（光線数挙動検証・プリセット追加・収差図タスクより優先）で着手する。P3-3（aperture runtime化）で導入した`iris_radius_mm`スライダーの視覚的効果に直結するため、優先度を上げる。

## 背景

人間から、Layout View上の絞り（STOP）記号・センサー（IMG）記号の大きさが、実際の`semi_diameter_mm`やセンサー寸法と対応しているか疑わしいという指摘があった。具体的には「絞りの表示よりも細い光束が飛んでいる」ことが確認されている。これは、光線経路が実データに基づくスケールで描かれているのに対し、STOP/IMG記号が固定長の装飾的マーカーとして描かれている可能性を示す。

## 作業

1. 現在のLayout View実装で、以下の記号の高さ（Y方向の描画範囲）が何に基づいて決まっているか確認する（推測せず、コードを確認する）：
   - `aperture_stop` / `mechanical_aperture`（STOP）
   - `sensor`（IMG）
   - `eye_reference`（該当プリセットがあれば）
   - 参考として、thin_lens・mirror・dummy等、他の要素種別も同様の問題がないか横断確認する。
2. 固定長・装飾的なサイズになっている場合、実際の値に基づくスケールへ修正する：
   - `aperture_stop`/`mechanical_aperture`：`aperture.semi_diameter_mm`（annulusの場合は`outer_semi_diameter_mm`）を、他の面と同じmm→pixelスケールで描画する。iris_radius_mmがruntime variableとして送られている場合（P3-3対応済み）、**現在有効な実効半径**（デフォルト値ではなくランタイム値）を反映する。
   - `sensor`：`sensor.width_mm` / `sensor.height_mm`（Y-X投影の場合は半対角またはheightの半分等、既存の投影規約に従う）を反映する。
3. **P3-3のiris_radius_mmスライダーと連動確認**：絞り半径スライダーをドラッグしたとき、STOP記号の高さが実際に変化することを確認する（現状、記号サイズが固定だとすればここで初めて連動するようになる）。あわせて、絞りを絞ったときに光線束の幅とSTOP記号の幅の関係が物理的に整合すること（光線束はSTOP記号の範囲内に収まる、絞りが十分開いていれば光線束がSTOP記号の縁に達する等）を確認する。
4. 複数プリセット（P002：絞りが比較的大きい/小さい、P005：annulus絞り、P006：afocal系のeye_reference）で、記号サイズが意図通りに変わることを確認する。
5. 極端に小さい/大きい`semi_diameter_mm`の場合に記号が視認できなくなる・逆に画面を占領しすぎる問題がないか確認する。最小視認サイズへのクランプが必要な場合は、クランプが発生していることが分かるようにする（クランプによって実寸と見た目が乖離する場合、何らかの視覚的インジケータを検討する。過剰実装は避け、必要なら報告のみに留めてIssue化してよい）。

## 完了条件

- STOP・IMG記号のサイズが実際の`semi_diameter_mm`・センサー寸法に基づいていることがコードで確認・修正されている。
- P3-3の絞りスライダー操作で、STOP記号のサイズが実際に追従することがスクリーンショットまたはE2Eで確認されている。
- 光線束の幅とSTOP記号の幅の関係が、複数プリセットで物理的に妥当であることを確認する。
- 完了報告前にプロセスを再起動し、`build_info.git_commit`がHEADと一致することを確認する（AGENTS.md規約通り）。

## 参考：これまでの経緯

このプロジェクトでは、Layout Viewにおいて「見た目はそれらしいが実データに基づいていない」描画（面の直線描画、光線経路の始点終点補間、aperture半径変更時のsystem再登録）が繰り返し見つかっている。本タスクも同じ系統の確認であるため、目視だけで判断せず、実際に使われているデータソースをコードで確認してから修正すること。
