# 波長色分けの実装確認 指示書（Codex向け）

## 背景

人間から「Optical Layout Viewやspot diagramで、波長（色）が実際に反映されているか」という確認依頼があった。エンジンは複数波長での光線追跡結果を返せるが、UI側がそれを実際に波長ごとの色分けで表示しているかは未検証。

## 作業

1. Layout View：Q1で実装された波長帯クラス分け（F線系/d線系/C線系）が、複数波長を指定したリクエストで実際に色分けして表示されることを、P003（アクロマート、複数波長比較用プリセット）で確認する。
2. Spot diagram：波長ごとに色分けされているか確認する。されていない場合、UI仕様の波長色規約（F=青系、d/e=緑黄系、C=赤系）に従って実装する。
3. 白色光源（`light_sources`/`wavelength_weights`）機能について、現在Workbench UIでこれを設定・利用できる導線があるか確認する。無い場合、これは意図的にスコープ外（白色PSF/MTF等の将来機能向け）なのか、Issue化すべき欠落なのかを判断し、報告する。
4. 上記の結果を報告する。実装済みであれば確認のみで完了、未実装・不整合があれば修正する。

## 完了条件

- Layout View・spot diagram双方の波長色分けの実装状況が報告されている。
- 不整合があれば修正されている。
- 白色光源対応の現状（意図的スコープ外かIssue化すべきか）が判断されている。
