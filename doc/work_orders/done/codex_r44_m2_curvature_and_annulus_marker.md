# R44：M2曲率符号・Annulus STOP位置とマーカー表示の再調査（R43の差し替え版）

**この指示書はR43（`codex_r43_m2_curvature_and_annulus_marker.md`）を取り消し、置き換えるものです。R43はまだ着手・実行していなければ破棄してください。着手済みの場合は、そこまでの作業内容を報告した上で本指示書（R44）の内容に沿って継続してください。**

## 背景

R42完了後、人間が実際にブラウザで確認したところ、まだ問題が残っている可能性がある。

1. **M2の曲率の向きが物理的に妥当か要確認**：画像を見た人間・AI双方の見え方が一致しておらず（凹に見える／凸に見える、という食い違いが会話中で発生した）、まず「現在M2がどちらの向きで描画されているか」を客観的に確定する必要がある。その上で、カセグレン式望遠鏡の副鏡M2として物理的に正しい向き（主鏡M1に対して逆向きの曲率）になっているかを判定する。
2. **STOPの位置がM2と重なって見える**：人間から「STOPがM2の位置にあるように見えるのは違和感がある」という指摘があった。R42の③の結論では、annulus絞りは「主鏡M1の中央開口」を表現するとされていたが、実際の描画ではSTOPマーカーがM1側ではなくM2の位置付近にあるように見える。位置の整合性を確認する必要がある。
3. **凡例とレイアウト図の不整合**：凡例に「STOP」（塗りつぶし丸）と「Annulus STOP（副鏡による中央遮蔽）」（輪郭丸）の2種類のマーカーが追加されているが、実際のレイアウト図にはオレンジの塗りつぶし丸が1つしか見えず、Annulus STOP用の輪郭マーカーが表示されていない。

**推測で修正を進めず、まず1・2・3それぞれの「現在の実際の状態」を客観的な事実（座標値、描画コード上の対応関係）として確定してから、正誤を判定すること。**

## 作業

### 1. 現状の客観的な確認（最優先）

1. P005のsystem定義における各要素（M1、M2、annulus STOP面）の`radius_mm`・`thickness_after_mm`・X座標（頂点位置）を、実際の数値として一覧化する。
2. Layout View描画コード上で、M1・M2それぞれの弧がどの`radius_mm`値を使い、どのようなSVGパス（またはそれに相当する描画命令）で弧の向きを決定しているか、実際のコードを引用して報告する。
3. annulus STOP面が、system定義上どの位置（X座標）に置かれているか確認し、それがM1側なのかM2側なのか、あるいは両者の中間なのかを明確にする。
4. 上記の客観的事実を報告した上で、次の段階（曲率の向きの正誤判定、STOP位置の正誤判定）に進む。

### 2. M2曲率の向きの正誤判定

1. 作業1で確認した`radius_mm`の符号と、仕様5.1節の符号規約（R>0は曲率中心が+X側、R<0は-X側）に基づき、M2が物理的にどちら向きに膨らむべきかを算出する。
2. カセグレン式望遠鏡の標準構成（副鏡は主鏡に対して凸、主鏡に向かって光を反射する）と照らし合わせ、現在の描画が正しいか判定する。
3. 誤っていれば、描画ロジックのどこで符号の解釈を誤っているかを特定し修正する。正しければ、その旨を報告し、今回の会話で「凹凸の見え方」について人間とAIの認識が食い違った原因（画像の解釈の難しさ、対称性、遠近感等）も一言添える。

### 3. STOP位置の妥当性確認

1. 作業1で確認したannulus STOP面の位置が、R42の③の結論（主鏡M1の中央開口を表現）と整合しているか確認する。
2. 整合していない場合（STOPがM2側にある等）、意図した位置（M1直前、または主鏡の開口位置）に修正する。

### 4. Annulus STOPマーカーの表示確認

1. 凡例に追加した「Annulus STOP（副鏡による中央遮蔽）」マーカーが、実際のレイアウト図のどの要素に対応する想定だったか確認する（STOP面自体の表現なのか、annulus遮蔽の視覚化なのか）。
2. なぜ実際のレイアウト図にこのマーカーが表示されていないか確認する（描画条件の見落とし、凡例だけ追加して実装が伴っていない等）。
3. 原因を特定し、実際にannulus遮蔽（中央開口）が視覚的に確認できる形で描画されるよう修正する。R42の③の結論（主鏡M1の中央開口を表現）を踏まえ、M1の描画に穴（欠け）を反映する対応が必要であれば、これも本タスクで実施する。

## 完了条件

- M1・M2の曲率の向きについて、客観的事実（radius_mm符号、描画コードの対応関係）が報告され、正誤判定の結果（修正が必要ならその内容）が明記されている。
- annulus STOP面の位置がM1側（主鏡の中央開口）として意図通りに配置されているか確認され、必要なら修正されている。
- Annulus STOPマーカーが凡例通りに実際のレイアウト図でも表示される、または凡例側を実態に合わせて修正する。
- 完了報告前にプロセスを再起動し、`build_info.git_commit`がHEADと一致することを確認し、断定形で報告に記載する（未来形で締めない）。
