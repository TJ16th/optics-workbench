# P005：annulus絞りのinner/outer半径がSystemタブに表示されない件の調査 指示書（Codex向け）

## 背景

人間がSystemタブの面テーブルを確認したところ、STOP行（`kind: aperture_stop`）の「有効半径 (Semi-Diameter)」列には`100`という単一の値のみが表示されていた。エンジン仕様6.4節のannulus絞りは`outer_semi_diameter_mm`（外径）と`inner_semi_diameter_mm`（内径、中央遮蔽の大きさ）の2つの値を持つ設計だが、現在のSystemタブの面テーブルには、この2つを区別して表示・編集する列が存在しない。

「ドーナツ状の遮蔽（annulus）の内径は、どこで決まっているのか」という疑問が生じている。

## 作業

1. **現状の客観的な確認（最優先）**：
   - P005のsystem定義（実際のJSON/YAML）で、STOP面の`aperture`定義がどうなっているか確認する。`shape: annulus`で`outer_semi_diameter_mm`・`inner_semi_diameter_mm`の2値を持つ形式になっているか、それとも単一の`semi_diameter_mm`（円形絞り相当）になっているか確認する。
   - Systemタブの面テーブルコンポーネントが、`aperture`定義のどのフィールドを「有効半径」列に表示しているか確認する。annulus形状の場合、outer/innerのどちらを表示しているか、あるいは両方を何らかの形で表示しようとしているか確認する。
2. **表示・編集手段の欠落確認**：
   - 現在のSystemタブに、annulus絞りのinner半径を表示・編集する手段（列、モーダル、詳細パネル等）が存在するか確認する。
   - 存在しない場合、これは実装漏れである。R40〜R45までの一連のannulus関連タスクで、annulus遮蔽自体は光線追跡・Layout View描画では扱われてきたが、**Systemタブでの表示・編集という基本的なUI機能が一度も対応されていなかった**可能性が高い。
3. **対応**：
   - Systemタブの面テーブルに、annulus形状の面ではinner/outer両方の半径を表示する列（または折りたたみ詳細）を追加する。
   - 可能であれば、inner半径をユーザーが編集できるようにする（editable cellまたは詳細パネル）。過剰な作り込みは避け、既存の「有効半径」列編集UIのパターンに準ずる形でよい。
   - annulus以外の形状（circle等）の面では、この追加列・詳細は不要（従来通り単一の有効半径表示のままでよい）。
4. 修正後、P005のSystemタブでSTOP行のinner/outer半径が両方確認・編集できることを確認する。

## 完了条件

- P005のsystem定義におけるSTOP面のannulus定義（outer/inner）の実際の値が報告されている。
- SystemタブでSTOP行のinner半径が表示される（編集可能であれば編集もできる）。
- annulus以外の面の表示に悪影響が無いことを確認する。
- 修正後のSystemタブのスクリーンショットを`doc/reports/screenshots/`配下に保存し、完了報告から参照する（R46の保存規約に従う）。
- 完了報告前にプロセスを再起動し、`build_info.git_commit`がHEADと一致することを確認し、断定形で報告に記載する（未来形で締めない）。

## この後

本タスクでinner半径がUIから確認・編集できるようになれば、R45（M1穴あき描画・M2サイズ調整）で使う値の出所も明確になる。R45とR47（本タスク）のどちらを先に実施してもよいが、R47でinner半径の実際の値が変わる可能性がある場合は、R45の描画確認をR47の後に行うほうが安全である。
