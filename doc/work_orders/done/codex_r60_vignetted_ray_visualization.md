# R60：M2等の有効径で蹴られた光線の追跡・可視化 指示書（Codex向け）

## 背景

R59の調査で以下が判明した。

1. `blocked`ステータスの光線は、2点以上のpathを持つ限り既に描画対象に含まれている（R33由来）。ただしP005のbaseline実例で確認できたのは**M1**の有効径で遮蔽された2本のみで、**M2**で実際に遮蔽される光線が存在するかは未確認だった。
2. `alive`と`blocked`が同じ線種で描画されており、光学系を見て「どこで光が蹴られているか」を視覚的に判別できない。
3. density ray側は、annulus開口帯の判定を半径`r=sqrt(Y²+Z²)`で正しく行っており（`abs(Y)`ではない）、実測でも問題なしと確認済み。ただしこの結果から、**Z成分を持つ光線をLayout View（Y軸のみの2次元断面）に投影すると、実際は開口帯内を通っていてもY座標だけ見ると開口帯の外を横切っているように見えるケースがありうる**という表示上の限界が新たに認識された。

人間の方針：**光学系を正しく把握するためには、M2のような面の外径エッジで蹴られる光線も、追跡した上で明示的に表示すべきである。** 「表示するか検討する」ではなく「表示する」ことを前提に進める。

## 作業

### 1. M2（および他面）での遮蔽実例の確認

1. P005で、recommended field・複数のray_aiming/samplingパターンを使い、M1以外の面（特にM2）で`blocked`となる光線が実際に発生するかを確認する。baseline（chief/marginal）で発生しない場合は、density ray側や他のプリセット・条件でも確認する。
2. M2で遮蔽される実例が見つかった場合、そのpath（どの面まで到達したか、Y/Z座標）を報告する。
3. 見つからない場合、その理由（例：現在のP005の光学設計ではM2の有効径が十分大きく、サンプリング範囲内では発生しない等）を報告し、意図的に発生させる条件（field角・絞り径等を変えた場合）があるかも触れる。

### 2. 遮蔽光線の視覚的区別を実装する

1. R59が提示した案のうち、専用線種案を採用する：`blocked`のbaseline光線を、`alive`と区別できるスタイル（低彩度・短い破線等）にし、終端（遮蔽が発生した面）に小さな終端マーカー（例：×印）を付ける。
2. 凡例に、blocked光線のスタイルを追加する（例：「Vignetted ray（遮蔽光線）」）。
3. density layerについては、blocked光線を常時大量表示するとLayout Viewが過密になるため、baseline（chief/marginal）のみを対象とし、density側は現状維持（今回はスコープ外）とする。
4. 修正後、P005（および可能ならM2遮蔽が実際に発生する条件）でスクリーンショットを取得し、alive/blockedが視覚的に区別できることを確認する。

### 3. 3次元光線の2D投影限界について（実装не要、記録のみ）

1. 「Z成分を持つ光線が、Y軸のみのSTOP開口帯表示と視覚的に矛盾して見えうる」という限界について、`doc/reports/issues_backlog.md`に将来検討事項として登録する（AGENTS.md「GitHub Issue運用」節のフォーマットに従う）。今回の実装対象には含めない。
