# AGENTS.md：同一コミットでのactive→done移動ルール追記

## 背景

R8（`codex_r8_work_orders_active_done_check.md`）の完了報告で「既存ルールで十分」と判断されたが、実際にAGENTS.mdを確認したところ、「タスク完了報告をdoc/reports/に追加する際、対応する指示書ファイルを**同じコミットで**active/からdone/へ移動する」という具体的な手続きルールは存在しなかった。

直近のQ2〜Q6・R1は結果的にdoneへ正しく移動されていたが、これはこのルールが存在したからではなく、別の経緯（棚卸し作業等）による。再発防止のため、ルールを明文化する。

## 作業

`AGENTS.md`の「作業規律」節に、以下を追記する（既存の関連ルールを削除・改変せず、追記のみ）：

```text
タスクの完了報告を doc/reports/ に追加するコミットでは、対応する指示書ファイルを
同じコミットで doc/work_orders/active/ から done/ へ git mv する。
別コミットに分けない（分けると active/ に指示書が取り残され続ける原因になる）。
```

## 完了条件

- 上記ルールがAGENTS.mdの「作業規律」節に追記されている。
- 追記後のAGENTS.md該当箇所を完了報告に引用する。
