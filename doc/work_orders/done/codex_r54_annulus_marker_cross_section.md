# R54：annulus絞りマーカーの断面表現修正 指示書（Codex向け）

## 背景

R51〜R53完了後のP005スクリーンショットで、annulus絞り（STOP、中央遮蔽を表すマーカー）が**正円（黄色い丸）として描画されている**ことが確認された。

Layout Viewは光学系の断面図（X-Y平面、光軸を含む面で光学系を輪切りにした図）である。M1・M2などの他の要素は、いずれもこの断面表現（曲率半径を反映した弧、または直線）で正しく描かれている。しかし、annulusのようなドーナツ状（円環）の開口を光軸方向の断面で見た場合、**正面から見た円形ではなく、光軸に垂直な方向（Y軸）の2点（内径の位置・外径の位置）における短い縦線として表現されるべき**である（例えば、内径Y=+40と-40の位置、外径Y=+100と-100の位置に、それぞれ短い縦線または点を描く形）。

現在の正円マーカーは、断面図の中に正面図（フロントビュー）の記号が混在している、幾何学的に不正確な表現である。

## 作業

1. Layout View描画コードで、annulus STOPマーカーがどのように描画されているか確認する（現在、正円として描画するロジックになっていることを確認する）。
2. 他の面（絞り・IMG等）が断面図としてどう描かれているか確認する（例えば通常の円形絞りSTOPは、Y軸方向の縦線として描かれていたはずである。これと同様の考え方をannulusにも適用する）。
3. annulus STOPマーカーを、断面図として正しい表現に修正する：
   - 内径（inner_semi_diameter_mm）の位置に、Y=+inner・Y=-innerのそれぞれに短い縦線（または線分）を描く。
   - 外径（outer_semi_diameter_mm）の位置に、Y=+outer・Y=-outerのそれぞれに縦線を描く（これは面自体の有効径線と重なる可能性があるため、重複しないよう調整する）。
   - 内径と外径の間（実際に光を通す環状の範囲）を示す表現があると分かりやすい場合は検討するが、過剰な装飾は避ける。
4. 修正後、通常の円形絞り（STOP、annulusでないもの）の描画表現と、視覚的な一貫性が保たれていることを確認する。
5. 凡例の「Annulus STOP」アイコンも、断面表現に合わせて修正する（正円のアイコンのままだと実際の描画と一致しなくなるため）。

## 完了条件

- annulus STOPマーカーが、正円ではなく断面図として正しい表現（内径・外径それぞれの位置に縦線等）で描画される。
- 凡例のアイコンも実際の描画と一致する。
- 修正後のLayout Viewスクリーンショットが`doc/reports/screenshots/`配下に保存され、完了報告から参照される（R46規約に従う）。
- 既存テストがグリーン。
- 完了報告前にプロセスを再起動し、`build_info.git_commit`がHEADと一致することを確認し、断定形で報告に記載する（未来形で締めない）。

## 注意

これはR43・R53に続き、視覚表現の妥当性を目視だけで見過ごしていた可能性がある案件である。修正後は、単に「それらしく見える」ではなく、**断面図としての幾何学的な正しさ**（他の面の描画表現との一貫性）を基準に確認すること。
