- R47とR48は互いに関連が深い（R47で確認するannulusのinner/outer半径の実態が、R48の絞り構成整理の前提になる）。**R47の完了後、その結果とR48の指示内容に矛盾が生じないか確認してからR48に着手すること。**

- いずれかのタスクで、想定外の発見（新しいバグ、仕様との矛盾、実装方針の分岐が必要な判断）があれば、そこでバッチを中断し、そこまでの結果を報告して停止すること。良かれと思って自己判断で対応を進めない。
