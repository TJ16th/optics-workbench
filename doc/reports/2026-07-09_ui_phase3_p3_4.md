- Date: 2026-07-09

## 実装内容

- 右ペインに `Decenter / Tilt` 操作パネルを追加した。
- 対象groupを選択し、以下をスライダーで操作できるようにした。
  - `shift_y_mm`
  - `shift_z_mm`
  - `tilt_y_deg`
  - `tilt_z_deg`
  - `roll_x_deg`
- `rotation_center.reference` を `from_surface_vertex` / `to_surface_vertex` から選択できるようにした。
- 操作値を `configuration.decenters` / `configuration.tilts` として `POST /v1/education/preview` へ送るようにした。
- P3-2/P3-3と同じpreview経路を使う。
  - debounce: `180 ms`
  - drag中: `samples_per_field = 5`, `ray_aiming.mode = paraxial`
  - drag終了時: 通常preview
- Layout Viewで、configuration対象groupに含まれる面を破線・太線・赤マーカーで区別した。
  - X-Y投影のため、`shift_y_mm` と `tilt_z_deg` は直接視覚化。
  - `tilt_y_deg` / `roll_x_deg` はconfiguration送信と解析結果で確認する。
