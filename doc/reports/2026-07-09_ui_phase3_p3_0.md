# UI Phase 3 P3-0 群操作対応プリセット確認・追加報告

作業日: 2026-07-09

## 概要

UI Phase 3の入口として、群編集・ズーム/フォーカス・decenter・tilt操作を試せるプリセットがあるか確認した。既存プリセットではP006にgroup定義があるもののafocal系であり、Phase 3の焦点系Layout View追従確認には不十分だったため、P003 Achromat Doubletを焦点系の操作用プリセットとして拡張した。

## プリセット確認

| Preset | 現状 |
| --- | --- |
| P001 | group / zoom_positionsなし |
| P002 | group / zoom_positionsなし |
| P003 | P3-0で `FOCUS_G` / `OIS_G` / `zoom_positions` を追加 |
| P004 | UI実装側の `apps/workbench-ui/src/domain/presets.ts` には未定義。仕様上はSimplified Double Gaussとして記載あり |

| P006 | `EYE_G` / `FOCUS` groupあり。ただしafocal系で、P3の焦点系スライダー確認には使いにくい |

## 追加内容

`apps/workbench-ui/src/domain/presets.ts` のP003に以下を追加した。

- `FOCUS_G`: `S1`〜`S3`
- `OIS_G`: `S2`〜`S3`
- `zoom_positions`
  - `infinity`: `FOCUS_G.shift_x_mm = 0`
  - `close_focus`: `FOCUS_G.shift_x_mm = 2`

また、`apps/workbench-ui/src/domain/types.ts` の `OpticalSystem` 型に `zoom_positions` を追加した。
