# UI Phase 3 P3-2 Report

## 対象

- Task: P3-2 ズーム・フォーカス位置のスライダー操作
- Date: 2026-07-09

## 実装内容

- 右ペインに `Group Motion` パネルを追加した。
- `zoom_positions` がある系では、ズーム位置を離散スライダーで選択できるようにした。
- フォーカス対象groupを選択し、X方向シフトを `-5.0` 〜 `+5.0 mm` の連続スライダーで操作できるようにした。
- Preview / Analysis / Best Focus 共通のAPIリクエストに `configuration` を送るようにした。
- スライダー操作中は、以下の低解像度previewをデバウンスして実行する。
  - endpoint: `POST /v1/education/preview`
  - `ray_aiming.mode`: `paraxial`
  - `samples_per_field`: `5`
  - debounce: `180 ms`
- ドラッグ終了時は通常設定のpreviewを実行し、結果をclean扱いに戻す。

## 採用値

- debounce: `180 ms`
  - 短すぎるとドラッグ中にAPI呼び出しが詰まりやすく、長すぎると教育用UIとして反応が鈍く感じるため、まず200ms弱の値にした。
- drag中preview: `5 rays / field`, `paraxial`
  - Layout View追従を優先し、通常解析条件より軽いpreviewに限定した。
